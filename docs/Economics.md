# Юнит-экономика Todo List

## Модель монетизации

Гипотетическая модель: freemium + подписка.

- Бесплатный тариф: локальный Todo List без синхронизации.
- Платный тариф: 100 руб/мес за синхронизацию, резервное копирование и расширенную аналитику.

## Предположения

| Показатель | Значение |
| --- | --- |
| Цена подписки | 100 руб/мес |
| Комиссии и налоги | 15% |
| Чистая выручка с пользователя | 85 руб/мес |
| Сервер и инфраструктура | 1000 руб/мес |
| Поддержка и прочие расходы | 2000 руб/мес |
| Общие постоянные расходы | 3000 руб/мес |
| CAC | 50 руб |
| Среднее удержание платного пользователя | 6 месяцев |

## Точка безубыточности

```text
Пользователи для выхода в ноль = постоянные расходы / чистая выручка с пользователя
3000 / 85 = 35.29
```

Минимально нужно 36 платных пользователей.

## LTV

```text
LTV = чистая выручка в месяц * срок удержания
LTV = 85 * 6 = 510 руб
```

## Соотношение LTV/CAC

```text
LTV / CAC = 510 / 50 = 10.2
```

Вывод: при заданных предположениях модель выглядит экономически жизнеспособной, потому что LTV существенно выше CAC. Главный риск - достижение стабильного удержания: если пользователь перестает пользоваться Todo List через 1 месяц, LTV падает до 85 руб.

## Что улучшать для экономики

- Добавить синхронизацию между устройствами как платную ценность.

- Сохранить бесплатный локальный режим, чтобы снизить барьер входа.
